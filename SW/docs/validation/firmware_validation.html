How to use this page
  1. Open this file in Chrome or Edge from the folder where validation_results.json is, and click Open results file to choose that file. From then on every result is written to it at once (other browsers: Save results file downloads it; put it back next to this page).
  2. Fill in the firmware under test. Its version is written with every result, so a later release keeps the results of the tests you do not repeat with the version they were passed on.
  3. Open a test, follow its steps on the device, then click Passed or Failed (a failure needs a note). The date and time are recorded. Undo last removes your last entry of that test.
  4. A test whose description changed after it was passed shows TEST CHANGED: repeat it. A test passed on another version than the one under test shows OLDER VERSION.
  5. Publish this page and validation_results.json together. Served over HTTPS the page is read-only; add #edit to the address to edit there.
